# Umsatzsteuer-Anwendungserlass (UStAE)

Der UStAE ist als Verwaltungsanweisung unter Steuerrecht abgelegt.

- [Strukturierte Fassung](Stand_2026-09-09/UStAE.md): Quellenstand **2. Juni 2026**, übernommen und mit der amtlichen BMF-Fassung abgeglichen am **9. September 2026**.
- [Quellen und Prüfhinweise](Stand_2026-09-09/README.md).

Frühere und spätere Fassungen erhalten jeweils einen eigenen Standordner.
