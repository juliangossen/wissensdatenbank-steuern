# Anwendungserlass zur Abgabenordnung (AEAO)

Der AEAO ist als Verwaltungsanweisung unter Steuerrecht abgelegt. Er ergänzt die [Abgabenordnung](../../Gesetze/Allgemeines_Steuerrecht/AO/README.md).

- [Strukturierte Fassung](Stand_2026-09-09/AEAO.md): Quellenstand **2. Juli 2026**, übernommen und mit den amtlichen BMF-Änderungsschreiben abgeglichen am **9. September 2026**.
- [Quellen und Prüfhinweise](Stand_2026-09-09/README.md).

Frühere und spätere Fassungen erhalten jeweils einen eigenen Standordner.
